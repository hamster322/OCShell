# Эмулятор VFS

## Описание
Данный проект представляет собой минимальный прототип эмулятора виртуальной файловой системы (VFS). На первом этапе реализован базовый графический интерфейс (GUI) с поддержкой диалога с пользователем, корректным парсингом команд и базовыми командами-заглушками.

## Реализованные требования
1. **Графический интерфейс (GUI):** Приложение реализовано с использованием стандартной библиотеки `tkinter`.
2. **Заголовок окна:** Окно приложения имеет заголовок **"VFS"**.
3. **Парсер команд:** Реализован корректный парсинг аргументов, включая полную поддержку аргументов, заключенных в кавычки (с использованием стандартного модуля `shlex`).
4. **Команды-заглушки:** 
   - `ls` — выводит свое имя и список переданных аргументов.
   - `cd` — выводит свое имя и список переданных аргументов.
5. **Команда выхода:** `exit` — корректно завершает работу GUI-приложения.
6. **Обработка ошибок:** При вводе несуществующей команды система выводит сообщение об ошибке и продолжает работу.

## Зависимости и установка
Для работы приложения требуется только стандартный интерпретатор Python. Никаких сторонних библиотек устанавливать не нужно.

- **Python:** 3.x
- **Библиотеки:** `tkinter`, `shlex` (входят в стандартную библиотеку Python).

## Запуск
Для запуска эмулятора откройте каталог с приложением и выполните скрипт запуска( start.sh для linux/macOs или start.bat для Windows)
