# Эмулятор VFS

## Описание
Данный проект представляет собой эмулятор виртуальной файловой системы (VFS). Проект развивается поэтапно:

**Этап 1:** Реализован базовый графический интерфейс (GUI) с поддержкой диалога с пользователем, корректным парсингом команд и базовыми командами-заглушками.

**Этап 2:** Эмулятор становится настраиваемым — добавлена поддержка параметров командной строки, возможность выполнения стартового скрипта с командами, отладочный вывод параметров и улучшенная обработка ошибок.

## Реализованные требования

### Этап 1
- **Графический интерфейс (GUI):** Приложение реализовано с использованием стандартной библиотеки `tkinter`.
- **Заголовок окна:** Окно приложения имеет заголовок "VFS".
- **Парсер команд:** Реализован корректный парсинг аргументов, включая полную поддержку аргументов, заключенных в кавычки (с использованием стандартного модуля `shlex`).
- **Команды-заглушки:**
  - `ls` — выводит свое имя и список переданных аргументов.
  - `cd` — выводит свое имя и список переданных аргументов.
- **Команда выхода:** `exit` — корректно завершает работу GUI-приложения.
- **Обработка ошибок:** При вводе несуществующей команды система выводит сообщение об ошибке и продолжает работу.

### Этап 2
- **Параметры командной строки** (реализованы через `argparse`):
  - `--vfs-path` — путь к физическому расположению VFS.
  - `--script` — путь к стартовому скрипту с командами эмулятора.
- **Стартовый скрипт:**
  - Выполняет команды эмулятора построчно.
  - Останавливается при первой ошибке (неизвестная команда и т.п.).
  - На экране отображается как ввод, так и вывод — имитация диалога с пользователем.
  - Пустые строки и строки, начинающиеся с `#`, игнорируются (поддержка комментариев).
- **Отладочный вывод параметров:** При запуске эмулятора в окне отображаются все заданные параметры (путь к VFS, путь к скрипту, имя пользователя, сеть, текущая директория).
- **Защита от некорректного запуска:** Если `--vfs-path` не указан, выводится сообщение об ошибке, поле ввода уничтожается, и окно автоматически закрывается через 2 секунды.

## Зависимости и установка

Для работы приложения требуется только стандартный интерпретатор Python. Никаких сторонних библиотек устанавливать не нужно.

- **Python:** 3.x
- **Библиотеки:** `tkinter`, `shlex`, `argparse`, `os` (входят в стандартную библиотеку Python).

## Запуск

Запуск производится с помощью настраиваемого скрипта. Базовый скрипт представлен в файле `run_test_without_args.sh`(linux) или `run_test_without_args.bat`(Windows). У скрипта есть флаги:
- `vfs-path` Обязательный флаг с указанием физического пути VFS
- `script` Опциональный флаг с указанием пути к стартовому скрипту

Пример скрипта для Linux
```bash
python ./src/main.py --vfs-path / --script /home/Hamak/PycharmProjects/OCShell/test_script.txt
```
